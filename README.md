# 实训室工位看板 · training-lab-board

多实训室、多工位的**实时状态看板**。面向实训室的教学与管理场景：
老师看得到每个工位在不在用、有没有报警；学生看得到哪个机位空着；
管理员看得到设备在线情况与资源分配。

浏览器打开一个页面即可，无需安装客户端。

---

## 它长什么样

一个页面，四个页签：

| 页签 | 做什么 |
|---|---|
| **S01 工位** | 校区 → 实训室 → 工位三级浏览，点开看单工位详情 |
| **S07 报警** | 按实训室 → 工位铺开**工位卡片**，一眼看清哪个工位有报警 |
| **S03 资源** | 机位占用看板：空闲几席、谁在用、什么时候到期 |
| **S05 指令** | 设备状态卡片 + 操作监护会话，含在线/离线/报警汇总 |

界面采用深空蓝 + 玻璃拟态的高校科技风格。

### 几个设计取向

- **工位卡片化**：16 个工位不再是平铺长列表，而是自适应卡片流；
  红卡=有未解除报警、蓝卡=仅有已解除报警、灰卡=无报警。
  **无报警的工位照样成卡显示「无报警」——不把它藏起来。**
- **术语收进折叠区**：界面上是「申请机位 / 续期 / 释放机位」，
  租约号、接口名、设备 MAC 放在「技术详情」里，需要排查时展开就有。
- **未上报 ≠ 离线**：从没上报过状态的工位显示「未上报」，
  上过报之后超时判离线的显示「离线」，两者语义不同不混用。

## 快速开始

需要 **Node.js ≥ 20.11**。

```bash
npm install
npm run serve:board
```

然后打开 <http://127.0.0.1:8731/>。

想换端口就传位置参数：

```bash
npm run serve:board -- 9000
```

### 其他命令

```bash
npm run typecheck   # 类型检查
npm test            # 单元测试（211 个）
npm run verify      # typecheck + test
npm run selfcheck   # 自检
```

## 数据从哪来

看板本身**不直连设备**。设备状态由上游按约定格式推送进来，
看板只做**投影与展示**——这是刻意的边界：

```
状态源（真机 / 网关 / 人工）
        │
        ▼
  StationProjection（投影：四状态 + 离线判定）
        │
        ├──► CampusCatalog（三级目录，纯结构，不含状态）
        ├──► BoardView（三级浏览 / 工位详情 / 统计）
        ├──► HistoryStore（历史状态）
        └──► RealtimeChannel（实时广播 / 兜底 / 重连恢复）
                    │
                    ▼
        createBoardServer（只读 HTTP，给前端）
```

**一条硬纪律**：工位状态**只做投影，绝不由资源池水位（占用数/容量）反推**。
「池子满了」不等于「所有工位都被占用」，这两件事必须分开判断。

```

  src/                  投影 / 目录 / 视图 / 历史 / 实时通道 / HTTP
  public/               前端页面与静态资源

  test/                 单元测试
```

## 编码规范

工位编码在代码里是**强校验**的，格式不对会被直接拒绝：

| 对象 | 格式 | 例子 |
|---|---|---|
| 校区 | `CAMPUS-<2位>` | `CAMPUS-01` |
| 实训室 | `LAB-<2位>` | `LAB-05` |
| 工位 | `ST-LAB<2位>-<2位>` | `ST-LAB05-02` |
| 资源池 | `RP-<SEAT-LAB<2位>\|VU-<3位>\|INST-<2位>>` | `RP-SEAT-LAB05` |

## 关于仓库中的示例数据

`services/board-web/public/site-live.ts` 与相关台账文件里带有**一套真实实训室的
设备档案**（内网 IP 段、设备 MAC、PLC 型号与序列号、工位站名），
用于展示真实的设备组成与归属判定逻辑。

这些是 **RFC1918 私网地址**，不可从公网直接路由。若你要把这个项目
部署到自己的环境，请把台账换成你自己的设备清单——
它们是**配置数据**，不是代码逻辑的一部分。
